# Калькулятор

Простой веб-калькулятор на HTML/CSS/JS. Работает в браузере, без сервера.

## Возможности
- Базовые операции: `+`, `-`, `×`, `÷`, `%`
- Ввод с кнопок и с клавиатуры (Enter, Backspace, Esc, цифры)
- История выражения на экране

## Запуск
Открой `index.html` в браузере, либо перейди по ссылке GitHub Pages:

https://zhamulaevraza-debug.github.io/calculator/
